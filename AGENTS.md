# AGENTS.md

## Deviations from the shared plugin architecture (G51)

- **`src/platform-ex.ts` is the single place the plugin casts `Platform`.** `Platform.version` (the APP version) and `Platform.build` (the INSTALLER version) are populated by Obsidian at startup — `app.js:226329-226330` — but `PlatformEx` in `obsidian-typings` declares neither. Every read of them, of `process.versions.electron`, and of the two `ipcRenderer.sendSync` probes goes through this one module, so there is exactly one cast in the plugin. When the typings declare them, the local `PlatformVersions` interface is deleted and the casts become plain reads; nothing else changes. Tracked as `T681-P8`.
- **`ipcRenderer.sendSync('insider-build', null)` must keep its `null`.** That channel is read/write: with a boolean it WRITES the setting (`app.js:202189`), and only `null` reads it (`app.js:202186`). A unit test asserts the argument, because the call reads like a stray parameter waiting to be tidied away and tidying it away would silently switch a user's release channel.
- **`MIN_RECOMMENDED_ELECTRON_VERSION` in `src/release-streams.ts` is hard-coded to `28.2.3`**, mirroring the constant Obsidian compiles into its own bundle (`app.js:222745`, compared at `:160712`). There is no API in front of it. Re-check it against `obsidian-versions` when a new Obsidian version lands. Note the plugin deliberately does NOT repeat Obsidian's own label for that check — Obsidian calls it "installer version too low" while what it compares is the Electron version, and the panel names Electron.
- **`src/obsidian-releases-api.ts` caches nothing, on purpose.** One check fetches all three feeds and hands the payloads to the stream resolvers together, so two streams cannot disagree about the state of the same check. A cache would add exactly that failure mode and save nothing at an hourly interval.
- **The changelog for a version with no public release comes from `https://obsidian.md/changelog.json`, not from scraping the HTML index.** The JSON Feed is structured and carries the full history (484 entries as of 2026-08-29) rather than the ~21 the HTML index renders — which matters because a Catalyst-only version has no GitHub release to read a changelog URL from and can be far enough back that the index no longer lists it.
- **`semver` is used at runtime** by `src/release-streams.ts`, to compare versions. Same use as in `obsidian-custom-attachment-location`.
- **No `i18next`; English-only**, as the fleet's newer plugins are. A plugin that later needs translations reinstates `t` from `obsidian-dev-utils/obsidian/i18n/i18n` AND an `src/i18n/i18next.d.ts` augmenting `CustomTypeOptions`.
